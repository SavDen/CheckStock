# Проверка перед сдачей

Дата: 12 ноября 2026.

## Подтверждено

- Python 3.12, FastAPI 0.115.12, SQLAlchemy 2.0.41, PostgreSQL 18.6.
- Миграции Alembic применены к пустым базам приложения и тестов.
- `pytest -q`: **23 passed**. Повторно проверено на PostgreSQL, который запускает `scripts/local.py`; тесты используют отдельную базу `_test`.
- Тесты включают одновременные резервы, одновременную приёмку и четыре повтора одной команды с одинаковым UUID.
- `ruff check app tests alembic scripts`: проверки пройдены.
- `node --check app/static/app.js`: синтаксические ошибки не найдены. Node нужен только для этой дополнительной проверки, не для приложения.
- `bash -n start.command`: синтаксические ошибки не найдены.
- PostgreSQL bootstrap: распаковка чистого пакета, восстановление ссылок и запуск `postgres --version` проверены отдельно.
- `./start.command` запустил приложение с постоянной базой в `.local/pgdata`. Исходный экран: 25 на ФФ, 25 доступно, резерв 0, в пути 0.

## Проверено через настоящий интерфейс

Приход 5 на Север; резерв FBS 3; отправка FBS; отказ FBO 14 при 12 на выбранном ФФ и 6 на другом; успешный FBO 4; отправка и приёмка перемещения 2 Север→Юг; архивирование Севера с 11 единицами; создание и переименование Востока; завершение FBO/FBS после архивирования исходного ФФ; создание и отмена нового резерва с Юга; поиск по истории.

Скриншоты проверены на 1440px и 390px. Таблица на узком экране прокручивается внутри контейнера. Отдельный визуальный обзор завершился вердиктом `ship`, обязательных исправлений не было. Загрузчик Impeccable был недоступен по правам исполнения; его автоматический детектор не запускался.

## Видео

Обзор длительностью около 4 минут 34 секунд собран из реальных кадров приложения. Русская озвучка синтезирована голосом Milena. Есть дорожка субтитров и отдельный SRT. Декодирование, наличие звука и контрольные кадры проверены. Это подготовленный обзор; для личной защиты кандидата приложен сценарий.

## Ограничение проверки

Docker на этой машине не установлен. Compose YAML прочитан парсером, Dockerfile и пути рассмотрены, но сборка и запуск контейнеров здесь не выполнялись. Workflow GitHub Actions подготовлен для PostgreSQL 17 и начнёт исполняться после загрузки в GitHub; успешный запуск CI пока не заявляется.

Pytest показывает одно предупреждение о совместимости версий Starlette/AnyIO (`BlockingPortal` deprecated); оно не влияет на результаты проверок.
